识别模型（LLM）

MinerU 识别出的内容要交给大模型整理成题目。不配这里也能用——会走 内置默认 DeepSeek（读 vendor/project_alpha/.env，老行为），但那条路的 max_tokens 写死 8192，换推理模型会因思维链占满预算而「返回空内容」。 支持任意 OpenAI 兼容接口（DeepSeek / 阿里云百炼 / 硅基流动 / 中转站 / 自建等）。 可以存多套，在列表里点「启用」随时切换，同时只有一套生效。

Base URL：填 API 根地址即可，会自动补全 /v1， 也不用管 /chat/completions 后缀——中转站直接填域名（如 https://yapi.click）就行，和 CC Switch 里的写法一致。

max_tokens：推理模型（如 deepseek-v4-pro）的思维链和正文共用这份预算， 填小了会思维链占满、正文一个字都不吐，建议 32000 以上；非推理模型（如 deepseek-chat）8192 够用。

API Key 以密文存库（密钥在 data/.enc_key），页面不回显。 删掉那个密钥文件已存的 Key 就解不开了，需要重新填。
