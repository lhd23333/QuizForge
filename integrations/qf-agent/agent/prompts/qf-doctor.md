---
description: 题库体检：结构风险、缺解析、图片引用与题型异常
argument-hint: "[目录，默认当前工作目录]"
---
对 ${1:-当前工作目录} 做一次题库体检，只读，不改任何东西。逐项检查并汇报：

1. **缺解析**：筛选出没有解析（solution 为空）的题，列出 id 与题干首行。
2. **题型可疑**：选择题但选项不足 4 个、填空题没有空、解答题没有小问。
3. **图片问题**：正文引用了 `![[...]]` 但文件里只读不到图的题（用 `grep` 或 `read_question` 核对）。
4. **题目结构**：题号断档、正文里混入解析标记（如正文含「解析：」）的题。
5. **空壳题**：题干极短（比如少于 5 个字）的题。

按严重程度排序，用表格给出 id / 目录 / 问题 / 建议动作。
最后给一句总结：「共 N 道题，其中 M 道需要处理」。没有问题就说"体检通过"。
