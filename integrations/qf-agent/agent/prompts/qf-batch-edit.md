步骤：
1. 先用 `filter_questions` 把**将被修改的题目**完整列出来（id / 目录 / 题型 / 难度），
   并明确说出"这次要改 N 道题，改的是哪个字段，从什么改成什么"。
2. 等我确认后再调用 `bulk_update_questions`（一次调用改完，不要拆成多次）。
3. 改完用只读工具复核一遍，报告「实际改了几道」以及快照 id（用于回滚）。

如果我的要求有歧义（比如同时指定了冲突的筛选条件），先问清再动手；
不要用"可能""大概"这类模糊判断去扩大修改范围。
