# QuizForge 软件版当前状态

> 当前快照：2026-08-31。本文只记录本仓库本轮仍有效的实现、验证和交付状态；历史变化见 [`../CHANGELOG.md`](../CHANGELOG.md)。

## 当前目标

本轮围绕统一桌面工作台、可靠题卡编辑、Codex 风格 Agent、提示词与带图导入、安全自定义模板完成闭环改造，并定版为 `v2.0.0`。现有题库格式、用户数据、导入导出默认语义和固定安装器身份保持兼容；用户已明确授权正式构建、覆盖升级验收、源码推送和小范围私测，但可信签名完成前不创建公开 tag、GitHub Release 或更新清单。

## 已落地实现

- 全站单选下拉保留原生 `select` 为表单值源，并增强为圆角 listbox，支持说明、搜索、键盘、焦点恢复、表单 reset 和动态选项。题库、导入、讲义、编辑、设置与 Agent 按“主流程常驻、高级设置折叠”重排，窄屏回落单列。
- 文件树已拆分“子节点已加载”和“当前已展开”，只强制展开活动题集祖先，手动状态按题库保存在当前窗口 `sessionStorage`。题目选择统一兼容布尔值与旧 `0/1`，局部替换、编辑回写和无限滚动均从服务端状态恢复。
- 题卡原地编辑、新题草稿和独立编辑页共用内容驱动的解析／备注折叠语义；有内容默认展开，空内容默认折叠，textarea 在 84–280px 内增高，预览勾选仅属于当前编辑会话。
- Agent 已改为无头像并排工作区，支持安全 Markdown／KaTeX、SSE 增量消息、可展开工具状态、幂等取消和部分回复保留。Chat Completions 与 Responses API 的流式文本和工具参数统一聚合，不完整终态不得执行工具，终态只落盘一次。
- 标准模式继续逐次审批本机命令、题库写入、付费转换和模板操作。危险模式需在当前会话显式确认警告后临时授权，可免确认执行具有当前 Windows 用户权限的本机命令及受控操作；切换会话或应用重启即失效，硬校验、操作锁和审计不受影响。
- 侧栏新增提示词库，两份官方提示词只读，本地自定义提示词支持完整 CRUD 和原子保存。导入支持直接粘贴 Markdown、逐题粘贴原图，以及带清单、入口 Markdown 和 `assets/` 的安全 ZIP；新资产按摘要去重，失败回滚后进入既有逐题校对。
- 设置页新增模板管理。目录 schema 已升级到 v2；可执行模板接受 UTF-8 TeX 或清单 ZIP，PDF 只作参考。模板必须通过 `$body$`／运行时宏／资源与危险原语检查，并在受限 TeX 工作区按全部声明模式真实编译、绑定源码哈希和确认预览后才可启用；导出继续以内置模板兜底。
