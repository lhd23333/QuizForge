## 当前目标

本轮将资料库能力并入题库主工作区，并收敛题库、导出和 Agent 的关键交互：题卡、PDF 与一般 Markdown 可按三个独立开关任意组合显示；文件在题库内预览、编辑、分栏和管理；原卷上传、导出选项、批量操作与 Agent 输入区改为更紧凑的按需展开布局。题库格式、讲义轻量接口、导出默认语义、用户数据和固定安装器身份保持不变；本轮仅同步日常目录版，不构建 Setup、不改版本或创建 tag。

## 已落地实现

- 桌面模式新增全局导航栏和题集栏的独立折叠恢复按钮，折叠状态写入 `localStorage` 并在刷新后保留；修复分栏拖动组件在无分隔条页面上提前退出、折叠到 0px 后仍被误判为可见以及内联宽度覆盖折叠样式的问题。
- 全站单选下拉保留原生 `select` 为表单值源，并增强为圆角 listbox，支持说明、搜索、键盘、焦点恢复、表单 reset 和动态选项。题库、导入、讲义、编辑、设置与 Agent 按“主流程常驻、高级设置折叠”重排，窄屏回落单列。
- 文件树已拆分“子节点已加载”和“当前已展开”，只强制展开活动题集祖先，手动状态按题库保存在当前窗口 `sessionStorage`。题目选择统一兼容布尔值与旧 `0/1`，局部替换、编辑回写和无限滚动均从服务端状态恢复。
- 题卡原地编辑、新题草稿和独立编辑页共用内容驱动的解析／备注折叠语义；有内容默认展开，空内容默认折叠，textarea 在 84–280px 内增高，预览勾选仅属于当前编辑会话。
- Agent 已改为无头像并排工作区，支持安全 Markdown／KaTeX、SSE 增量消息、可展开工具状态、幂等取消和部分回复保留。Chat Completions 与 Responses API 的流式文本和工具参数统一聚合，不完整终态不得执行工具，终态只落盘一次。
- 标准模式继续逐次审批本机命令、题库写入、付费转换和模板操作。危险模式需在当前会话显式确认警告后临时授权，可免确认执行具有当前 Windows 用户权限的本机命令及受控操作；切换会话或应用重启即失效，硬校验、操作锁和审计不受影响。
- 侧栏新增提示词库，两份官方提示词只读，本地自定义提示词支持完整 CRUD 和原子保存。导入支持直接粘贴 Markdown、逐题粘贴原图，以及带清单、入口 Markdown 和 `assets/` 的安全 ZIP；新资产按摘要去重，失败回滚后进入既有逐题校对。
- 设置页新增模板管理。目录 schema 已升级到 v2；可执行模板接受 UTF-8 TeX 或清单 ZIP，PDF 只作参考。模板必须通过 `$body$`／运行时宏／资源与危险原语检查，并在受限 TeX 工作区按全部声明模式真实编译、绑定源码哈希和确认预览后才可启用；导出继续以内置模板兜底。
- `2026-08-31` 续修选择题选项布局：服务端为选项标签预留宽度，前端按当前容器实际尺寸在 4／2／1 列间复核并在宽度变化后恢复首选列数；题卡节点替换时同步解除旧尺寸监听。PDF 导出同时保护 `\text`、`\textbf`、`\textit`、`\hbox` 等文本参数，避免“其中”被改写为文本模式中的 `\mathrm{M}`，并修复普通文本带圈数字显示为命令源码。
- `2026-09-01` 将导出面板和行内编辑器改为按自身容器宽度降级：导出首行按 6／3／1 列、高级设置与编辑元数据按 4／2／1 列、页眉页脚和编辑工作区在窄容器中转为单列；所有输入和网格子项允许安全收缩，导出或编辑期间隐藏新增题目悬浮按钮。原卷面板也按容器宽度换行，长文件名不再被操作区压成逐字竖排。
- 已选题目改为右缘边签和原生模态抽屉，主内容宽度不再随选题数量变化。抽屉使用独立只读题卡，完整展示题型、难度、星标、题源、目录、题干及折叠的解析、备注和标签；详情按需加载并用 generation 丢弃迟到响应。`/api/selection` 增加权威数量和只读详情，`/api/handouts/selected` 及全部写接口保持不变。点击题干始终创建新标签并按原目录跨 30 题分页定位，连续点击、切换标签、关闭抽屉或目标失效都会取消旧任务。
- 图片重绘现在为每道题的每张图片保留原图和 AI 生成版本历史，记录模型、时间与附加要求；题卡可查看缩略图、切换版本并删除不再使用的生成版本，原图和共享资源受到保护。
- `2026-09-04` 题库文件工作区移除固定分栏控制条，顶部文件标签支持拖动排序；拖入内容区会自动建立最多两栏的左右分栏，分界线支持鼠标和键盘调整并在当前会话记住比例，刷新后未激活标签也可直接拖入分栏。
